# 59 faixas novas — créditos e destino

Todas **CC0** (domínio público), colhidas via API do Openverse em 21/08/2026,
curadas por medição e normalizadas a −23 LUFS.

## Como subir (2 minutos)

1. Abra o painel do Supabase → **Storage** → bucket **`music`**
2. Arraste os **59 arquivos** da pasta `music-novas/` para dentro
3. Pronto — o código já aponta para esses nomes

⚠ Não renomeie os arquivos: os nomes estão escritos em `lib/pixabayMusic.ts`.

## O que foi reprovado, e por quê

De 76 candidatos baixados, **17 foram cortados**: efeito sonoro, gravação de
campo, um alarme, um ringtone, faixas com silêncio no meio e tudo abaixo de
−35 dB médio (esparso demais para servir de cama sob narração).

As sobreviventes foram **reclassificadas pelo título real**, não pela busca
que as encontrou — a busca por *peaceful documentary* trazia *Street Thriller*
para o balde de natureza, que é exatamente o erro que gerou a trilha sem
sinergia em 09/07.
